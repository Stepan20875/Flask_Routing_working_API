Команды управления миграциями:

Основные команды, которые становятся доступны:


flask db init - создает папку migrations, где будут храниться все миграции
flask db migrate - создает новую миграцию на основе изменений в моделях
flask db upgrade - применяет миграции к базе данных
flask db downgrade - откатывает миграции

Как это работает под капотом:

Когда вы делаете изменения в моделях SQLAlchemy, выполнение flask db migrate создает новый файл миграции
Этот файл содержит:
Версию до изменений (down_revision)
Версию после изменений
Функции upgrade() и downgrade()

 Запуск приложения:


Сохраните все файлы.
Откройте терминал, перейдите в папку my_blog.
Запустите приложение командой: python app.py
Откройте браузер и перейдите по адресу http://127.0.0.1:5000/ (или адресу, указанному в терминале).
